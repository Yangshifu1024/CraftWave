# CraftWave 入门示例技能

这是一个**内置示例技能**，用于演示 CraftWave 的技能系统：

1. 一个技能一个目录，目录内必有一份 `SKILL.md`；
2. 头部 YAML frontmatter 声明 `name` 与 `description`（模型平时只看到简介）；
3. 正文（本段文字）只在模型经 `skill` 工具加载后才进入上下文。

## 按本技能行动

当用户让你「演示技能」时：

- 用一句话向用户确认技能正文已按需加载成功；
- 简述渐进披露机制：简介常驻上下文、正文按需加载、不撑会话预算；
- 提示用户可以把本目录复制到全局（`~/.craftwave/skills/`）或项目
  （`<项目主目录>/.craftwave/skills/`）技能目录改造出自己的技能。

## 目录内附加资源

本目录下的 `greeting.txt` 是随附资源文件示例——技能正文可引用相对路径
资源（脚本、模板等），它们随本技能整体参与版本指纹与信任核验。
