## 1. 安装（未签名口径）

| 平台 | 产物 | 安装 | 首启放行（未签名） |
|---|---|---|---|
| macOS（仅 Apple Silicon） | `CraftWave_<ver>_aarch64.dmg` | dmg → 拖入 Applications | 右键「打开」一次；或 `xattr -cr /Applications/CraftWave.app` |

> macOS 不再支持 Intel：2026-10-28 用户决策，PRD FR-16-01 的 universal（x64+arm64）口径随之收窄为 arm64-only。
| Windows | `CraftWave_<ver>_x64-setup.exe`（nsis） | 双击安装 | SmartScreen「更多信息 → 仍要运行」 |
| Linux | `.AppImage` / `.deb` | `chmod +x` 直跑 / `sudo apt install ./<deb>` | — |

验证：应用能启动、三栏界面出现、退出后托盘/单实例行为正常即算安装通过。

## 3. 首日功能走查（P0 面一次过）

- 会话基本链路：发消息 → 流式打字机 → 思考流 → 工具卡参数流 → run 结束折叠总结。
- 权限四档：Shift+Tab 切档；command/plan/ask 审批弹出与放行/拒绝；plan 门（approve_plan）。
- 多会话与项目：多 Tab 并行、项目注册、临时会话、@ 补全（相对路径口径）、↑↓ 历史、草稿恢复。
- 模型选择（Composer 下拉，惰性生效）、运行中排队（第二条消息入队自动续发）。
- 持久化交互：分支/编辑/重生成、重启收养历史、工具输出恢复（toolres）。
- 桌面面：关闭到托盘、托盘唤起、退出拦截（活跃 run 确认框）、系统通知（失焦触发 + 点击回跳）、单实例二次唤起、主题三态、Inspector 用量三数、滚动跟随/回底。

## 4. 每日例行（≥1 轮真实任务 + 强杀核查）

1. 正常使用若干轮（改代码、查文件、跑命令等真实任务）。
2. **强杀核查（NFR-06，每天至少一次，轮换场景）**：
   - a. 运行中强杀（`kill -9` / 任务管理器结束进程）→ 重启：历史完整、该 run 标「已中断」、无半写段；
   - b. 审批挂起态强杀 → 重启：挂起恢复、可放行延续（14 号票跨重启语义）;
   - c. 分支/编辑/重生成后立即强杀 → 重启：树结构与操作前一致；
   - d. 断电/系统强制重启等价于 a（遇到即记录）。
3. 当天记录一行（§6 模板）。
