# CraftWave M2 正式版 1.0 规格

Status: ready-for-agent

> 上游依据：`docs/功能需求文档.md` v1.0（P1 行）与 `docs/技术设计文档.md` v2.9（M2 章节字段级）。执行拆解见本目录 `map.md`（七组执行图景）与 `tasks/01–36`（施工级票）。本文是该里程碑的问题—方案—验收视图；字段级实现口径以技术设计文档与各票为准。

## Problem Statement

M1 MVP 已可日常自用（多会话、八个工具、审批四档、流式输出、托盘后台、三平台打包），但用户以真实项目重度使用后宣布 M1 强制收官，并明确：**缺少一部分 M2 功能就没法正常使用**。缺口集中在：

- **长会话不可持续**：上下文涨满即报错或变笨，没有压缩；聊得越久越不能用。
- **运行态脆弱**：窗口重载/崩溃后运行中任务只剩只读快照；想排队续发消息没有 followUp；工具只能串行执行。
- **能力面窄**：不能接 MCP、没有技能系统、没有子代理；不能上网搜索/抓网页；不能读 Office/PDF 文档；不能发图片给 AI 看。
- **信任与安全纵深不足**：命令围栏只到正则级；AI 可篡改应用内部配置文件；项目里的技能/MCP 配置没有信任机制；计划门没有批准基线与范围扩张防线。
- **可运营性差**：花销只在会话内可见（无跨日/跨模型统计与供应商余额）；无会话日志可排障；无自动起名、导出、产物回看等管理面。
- **分发不体面**：macOS 未签名（每台新机要右键放行）、无应用内更新；无英文界面、无首启引导；git 状态全程黑盒。

## Solution

交付 M2（正式版 1.0）= **P1 全集（除多 Key 池轮换，用户砍单）+ M1 欠账清偿**，共 36 张票分七组推进（基建欠账 → 会话核心 → Agent 能力 → Provider 计量 → 安全纵深与 git → 桌面收尾 → 终局关）。完成后用户获得：长聊不失忆、断线重连不丢内容、可排队续发、AI 可并行干活；可接 MCP/装技能/派子代理；可上网（本地 SearXNG → 直接抓取 → Tavily 三通道）；可读文档、发图读图；Thinking 档位、连接测试、网络代理、本地模型；花销可查（用量面板 + 余额配额卡）；AST 命令拦截、内部状态防篡改、项目资源 TOFU 信任、外部目录授权、计划门基线/范围门；git 状态与变更可视（AI 写操作默认禁）；会话自动起名、可导出、产物面板；窗口几何记忆、Toast、全局热键、首启引导、中英双语；macOS 签名公证 + 应用内更新。出口另含全 NFR 达标与契约/回归体系上线；终局关为用户真实使用稳定验收（用户自验）。

## User Stories

**会话核心**

1. 作为重度用户，我要让长对话在接近上下文窗口时自动压缩，以便无限聊下去而不失忆不报错。
2. 作为用户，我要一个手动压缩按钮，以便在我想省额度时主动整理历史。
3. 作为用户，我要压缩后仍能回看全部历史消息，以便压缩不等于丢记录。
4. 作为用户，我要窗口重载或崩溃后运行中的任务无缝续流到界面，以便长任务不被 F5 毁掉。
5. 作为用户，我要在事件丢失时前端自动对账自愈，以便界面状态永远可信。
6. 作为用户，我要在 AI 干活时用 Alt+Enter 排队下一条消息，以便想到什么立刻说而不用等 run 结束。
7. 作为用户，我要中止运行时排队的消息被返还，以便不丢输入。
8. 作为用户，我要让 AI 同批执行多个互不冲突的工具，以便跑批量任务更快。
9. 作为用户，我要同批的文件写保持串行，以便不出现交错写坏文件。

**MCP**

10. 作为用户，我要在设置里登记一个全局 MCP 服务器，以便它的工具对全部会话可用。
11. 作为用户，我要在项目里放一份 MCP 配置覆盖全局，以便不同项目用不同工具集。
12. 作为用户，我要配置文件里的未知字段保存后不丢，以便版本升级兼容。
13. 作为用户，我要首次连接未信任的 MCP 服务器时被询问（本次/记住/拒绝），以便恶意配置不能静默启动。
14. 作为用户，我要在服务器配置变更后重新被询问信任，以便信任始终对应内容。
15. 作为用户，我要未声明只读的 MCP 工具即便在 full_access 档也弹确认，以便高危外部调用永远过人。
16. 作为用户，我要 MCP 断线自动重连且状态可见，以便长会话不掉链子。
17. 作为用户，我要在管理页对草稿配置做"测试连接"，以便保存前就知道配没配对。
18. 作为用户，我要 MCP 工具调用有卡片展示参数与结果，以便过程透明。

**技能系统**

19. 作为用户，我要把 SKILL.md 技能目录放进全局或项目目录即被识别，以便复用我积累的做事方法。
20. 作为用户，我要用 `/` 在 Composer 里触发技能，以便顺手加载。
21. 作为用户，我要技能正文按需加载而只有描述常驻，以便上下文不被撑爆。
22. 作为用户，我要在设置里启停/删除/重扫技能，以便管理我的技能库。
23. 作为用户，我要项目技能覆盖全局、全局覆盖内置，以便就近定制。

**子代理**

24. 作为用户，我要让 AI 派出 explore 等内置角色分身去干独立任务，以便主对话不被大范围搜索污染。
25. 作为用户，我要在输入框用 `$角色` 点名委派，以便显式指挥。
26. 作为用户，我要子代理过程实时展开可见，以便盯着它干活。
27. 作为用户，我要结束后在 Inspector 抽屉回看子代理历史，以便复盘。
28. 作为用户，我要取消主任务时子代理被级联终止，以便不留僵尸进程。
29. 作为用户，我要子代理有并发与步数/预算上限，以便不被失控循环烧钱。
30. 作为用户，我要写入子代理在独立工作区修改，由主代理回收并解决冲突，以便并行修改不会直接互相覆盖。

**上网与工具**

31. 作为用户，我要 AI 能搜索网络，以便查文档、查报错。
32. 作为用户，我要在设置里启用本机 SearXNG（独立配置组：开关/地址/连通测试），以便搜索完全走本地、零账号。
33. 作为用户，我在没配 SearXNG 时也要能搜（内置直接抓取 + 应用代理），以便零配置开箱即用。
34. 作为用户，我可以选择性配置 Tavily Key 作为最稳兜底，以便前两层都失效时仍有搜索。
35. 作为用户，我要工具卡标注结果来自哪条通道，以便知道走的是本地还是云。
36. 作为用户，我要 AI 能抓取网页正文（Readability 提取），以便读文章原文。
37. 作为用户，我要 SSRF 防护拒绝私网/回环等目标，以便恶意 URL 不能借 AI 探内网。
38. 作为用户，我要 AI 批量读文件，以便大范围调研更快。
39. 作为用户，我要 AI 按文件名模式找文件，以便不依赖我告诉它路径。
40. 作为用户，我要 AI 用精确计算工具算数，以便不被 LLM 算错坑。
41. 作为用户，我要 AI 产出的 HTML 能在沙箱预览面板打开，以便不离开应用看效果。

**文档与图片**

42. 作为用户，我要 AI 能读 docx/xlsx/pdf 内容（含表格），以便处理我的资料。
43. 作为用户，我要在输入框直接发图片（附件/拖拽/粘贴，≤4 张），以便给 AI 看截图。
44. 作为用户，我要用非 vision 模型时被前置拦截附图，以便不白花钱。
45. 作为用户，我要重启后历史图片还在消息里，以便回看完整上下文。
46. 作为用户，我要 AI 能用 read 工具主动读图，以便它自己查资料。

**Provider 与计量**

47. 作为用户，我要按会话切 thinking 档位，以便难题深思、简单题省钱。
48. 作为用户，我要会话记住我选的模型与思考档，以便重启不重设。
49. 作为用户，我要 Ctrl+L 快速切模型，以便不进设置页。
50. 作为用户，我要保存 Provider 前做连接测试并给分类错误，以便配错当场知道。
51. 作为用户，我要网络代理 none/system/manual 三模式且热生效，以便公司网/家网都能用。
52. 作为用户，我要一键接 Ollama/llama.cpp 本地模型，以便离线也能干活。
53. 作为用户，我要用量面板看按模型/按日的 token 与缓存命中率图表，以便掌握花销。
54. 作为用户，我要 Inspector 里看当前供应商的余额/配额卡，以便余额不足前有感知。

**安全纵深与 git**

55. 作为用户，我要命令围栏升级到 AST 级写目标分析且解析失败按保守处理，以便绕过写法（变量拼接/symlink）拦得住。
56. 作为用户，我要写文件后自动校验编码与完整性，以便静默写坏当场暴露。
57. 作为用户，我要文件工具和可检查的命令写目标不能篡改配置/凭据/MCP 配置等内部状态，灰区命令经审计定性、必要时人工确认，以便降低应用被修改损坏的风险（Q23–Q26 保护边界）。
58. 作为用户，我要同一命令会话内免重复批、常用命令进白名单，以便审批不烦人。
59. 作为用户，我要项目里的技能/MCP/项目指令首次加载时做信任决策，以便陌生仓库不带枪上车。
60. 作为用户，我要 AI 访问项目外目录前须我"始终允许"授权，以便边界我说了算。
61. 作为用户，我要批准计划后范围扩张被询问、计划完成后继续写被拦（E_PLAN_STALE），以便大任务不跑偏。
62. 作为用户，我要 AI 长时间不更新计划时被注入提醒，以便纪律不靠自觉。
63. 作为用户，我要面板上看 git 状态与聚合 diff，以便 AI 改了什么一目了然。
64. 作为用户，我要 AI 默认不能 commit/push/merge（白名单可放开 stage/commit、push 恒确认），以便版本历史只能由我推动。

**管理面与桌面**

65. 作为用户，我要新会话自动起名，以便列表里找得到。
66. 作为用户，我要把会话导出 Markdown/JSONL（含工具记录），以便留档与分享。
67. 作为用户，我要产物面板登记会话写过的文件并可一键打开，以便找产出不用翻聊天记录。
68. 作为用户，我要 @ 引用真实路径 chip 且发送时合成引用，以便 AI 精确知道我指哪个文件。
69. 作为用户，我要记住窗口位置尺寸且多显示器越界能回落，以便天天开在老地方。
70. 作为用户，我要操作反馈用顶部 Toast 轻提示，以便不被弹窗打断。
71. 作为用户，我要配置"关闭到托盘还是直接退出"，以便符合我的习惯。
72. 作为用户，我要全局热键一键唤起/隐藏应用，以便随时呼出。
73. 作为用户，我要首次启动有向导（语言→供应商→项目→安全简介，每步可跳过），以便新机十分钟上手。
74. 作为用户，我要一键切换英文界面，以便需要时演示给非中文同事。
75. 作为用户，我要会话级日志面板（verbose 含脱敏后的完整请求响应），以便排障有据。
76. 作为用户，我要应用内检查并安装更新，以便不用手动下载安装包。
77. 作为用户，我要 macOS 包已签名公证，以便新机安装不用右键放行。

## Implementation Decisions

> 2026-10-29 本轮 Q1–Q30 已逐项获用户确认。以下为最终口径；具体实现与验收见对应票，取代访谈中间方案。

- **里程碑切分**：36 票七组（A 01–03 / B 04–07 / C 08–17 / D 18–21 / E 22–28、36 / F 29–34 / 终局关 35）。新增 36 归 E 组，依赖 22+23，34 收口依赖 36，35 仍依赖 33+34；原依赖 02←01、06←05、13←11、16←15 不变。
- **契约面**：维持 ts-rs 12 生成 payload（生成物进 git、cargo test 导出校验）与手写键面 manifest 双向扫描，不引入 tauri-specta；再评触发仍为 specta 2.0 stable 或 M3+ 命令面再翻倍。
- **上下文与压缩**：每次模型请求前检查实际发送内容并预留回复空间，覆盖首次输入、工具结果、图片与模型切换；上下文占用独立于累计消耗。自动阈值为窗口占比 0.6，另有手动压缩；完整历史保留，wire 从摘要边界重建。超预算先压缩；失败后原上下文可容纳则继续，否则暂停保留输入并提示重试或新会话，不静默裁掉未经摘要的历史。压缩实际用量计入会话、不增主轮次。见 [04](tasks/04-impl-compaction.md)。
- **恢复与待发队列**：attach_run 用 512 帧环形缓冲与 sinceSeq 重放，快照对账自愈；续流针对 Rust run 仍存活的 WebView 重载/崩溃，Rust 进程崩溃仍沿用 interrupted 恢复，不承诺自动续跑。重连恢复有效审批及原始操作参数，关闭失效审批，不自动决定审批。followUp 后端队列仅正常完成后自动投递，失败持久暂停等待明确继续，取消返还草稿。见 [05](tasks/05-impl-attach-run.md)、[06](tasks/06-impl-followup-backend-queue.md)。
- **子代理调度与公共操作**：仅主代理可委派，子代理不再委派；跨会话共用并发上限，默认 4，设置页可修改并持久化。降低不取消已有任务，低于新上限后才补入；提高立即允许新增名额。公共操作仅主代理在相关子代理结束并收齐改动后执行，子代理可在自身工作区运行局部测试。见 [10](tasks/10-impl-subagents.md)。
- **子代理工作区与回收**：Git 写入子代理使用独立 worktree，只读任务读取当前工作区，非 Git 子代理只读。派发时复制当前状态（含未提交修改与未忽略新文件），之后不自动同步；主代理按起点差量汇回，冲突保留双方并解决验证，不覆盖用户已有修改，不自动 commit/push，不改变既有暂存状态。失败/取消保留未汇回成果，重启不自动续跑；成功汇回验证后清理。依赖按项目现有方式准备，不批量复制忽略文件，缺失配置交主代理协调。此方案取代共享目录跨子代理写认领，见 [ADR-0001](../../adr/0001-subagent-workspaces.md)。
- **项目资源信任与版本**：worktree 对原项目同资源同内容沿用对应作用域内信任，副本路径变化不重复询问，内容或 MCP 实际启动配置改变仍重核，跨项目不继承。每个 run 固定指令和技能版本，技能描述、正文与附属脚本/模板须同一整体版本；变更下一 run 加载并核验，安全权限撤销立即生效。见 [09](tasks/09-impl-skills.md)、[24](tasks/24-impl-trust-model.md)。
- **安全与计划范围**：保留 AST 围栏、字面量掩码、symlink 判定及内部状态硬拒；承诺覆盖可检查的写目标，不构成系统级沙箱。计划默认有计划即守门，批准时展示并冻结具体文件/目录范围，无范围的已批准计划首写也须确认，新增范围再次询问；E_PLAN_STALE 与默认关闭的硬门保留。见 [22](tasks/22-impl-ast-fence-postcheck.md)、[23](tasks/23-impl-internal-state-approval-memory.md)、[25](tasks/25-impl-plan-gate-p1.md)。
- **命令审计 Agent**：确定性硬拒/可靠只读不调用模型，灰区 command 单次无工具审计；低风险可放行，证据不足或失败转人工。硬规则、权限、计划范围、公共操作角色限制及明确人批不被豁免。专用模型可在设置页选择，未配跟随会话；独立提示词不带全历史，应用仅在授权目录只读收集脚本/定义/目标/批准范围。总等待 15 秒，显示审计状态、结论与简短理由；实际用量计入会话不增主轮次。MCP 不纳入本期审计，见 [36](tasks/36-impl-command-auditor.md)、[ADR-0002](../../adr/0002-command-auditor.md)。
- **MCP 断连**：连接可自动恢复，但已发出且结果未知的调用不自动重放，明确报告可能已执行，由主代理核查后决定重试，read_only 不豁免。见 [08](tasks/08-impl-mcp-client.md)。
- **网络搜索**：沿用 C-12 本地优先三通道 SearXNG → DuckDuckGo HTML 直接抓取 → Tavily BYOK；SearXNG 独立配置并探活，本地回环不经代理；直抓走应用代理，Tavily 仅已配置 Key 时参与。全败结构化错误，Brave 留位不实现；凭据沿用现有存储协议。见 [13](tasks/13-impl-web-search.md)。
- **图片与日志**：含历史图的会话切非 vision 后可纯文字继续，历史图仅在模型请求中占位并提示，界面原图保留；新附图与主动读图拒绝。日志只记图片实际路径/哈希/格式/大小，不含本体；无源路径附件记 blob 路径。删会话同步删专属日志与轮转副本，应用日志仅运行元数据、不留会话正文或图片。见 [17](tasks/17-impl-image-input.md)、[32](tasks/32-impl-session-logs.md)。
- **git**：git2 只读状态/差异/历史与变更面板；stage/commit 默认禁，开关开启后可经审批执行，merge/rebase 仍禁，push 恒确认、force push 恒禁。应用受控 worktree 管理与模型 git 命令分开授权。见 [26](tasks/26-impl-git-integration.md)。
- **签名与更新**：macOS 签名公证、tauri updater 与 GitHub Releases；开发构建缺 secrets 可退化，但不能代替签名正式包验收。运行时可检查下载，安装/重启前须无活跃任务或待审批请求；待发队列须用户明确暂停并保留，更新后保持暂停。Windows/Linux 维持未签名。见 [33](tasks/33-impl-signing-updater.md)。
- **范围与文档纪律**：多 Key 池砍单，i18n 收尾，虚拟滚动本体留 M3；Brave/成本统计/斜杠命令面板等 P2 仍不做。字段级缺失或过时处先回写技术设计再实现；本文记录的命令审计与 worktree 是本轮明确加入 M2 的范围，不因旧里程碑标注排除。

## Testing Decisions

- **好测试只测外部行为**：命令/帧/事件契约面、工具执行的可观察结果、UI 交互路径——不测内部实现细节。
- **全部沿用既有接缝，不新增顶层接缝**：① IPC 契约 = `export_ipc_manifest` + 前端 contract.test 双向扫描（扩展至 M2 命令/帧/事件全集，先例为 M1 manifest 测试）；② Rust 侧 cargo test 三件套（先例：storage roundtrip、围栏判定表、审批矩阵）；③ 前端 vitest（先例：消息树 roundtrip 11 例）；④ e2e = ScriptedBackend 全链（先例：M1 14 号票审批挂起 e2e、`e2e_tool_batch_cancel` Windows JobGuard 实跑）；⑤ 外部依赖一律 fixture/录制回放——MCP 用本地 echo server、SearXNG 用假服务、抓取与 Tavily 用录制快照（真实站点改版/限额不挂 CI）。
- **每票的具体测试接缝**在各票"测试"小节定义（含既有测试文件的扩展点），本规格不重复。
- 检查链口径不变：`cargo build/clippy/test`（src-tauri/）+ `pnpm typecheck/test/lint`（从仓库根跑），`MACOSX_DEPLOYMENT_TARGET=13.0`。
