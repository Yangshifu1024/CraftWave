# 会话删除保留无会话关联的用量聚合和完整升级备份

删除当前会话时清理正文、会话图片、专属日志和关联 run 明细；保留不含正文及会话关联的日/模型消耗数字，因为已发生的消耗不随聊天记录删除而消失。当前会话删除与抹除全部历史副本采用不同边界。

历史升级备份保持完整，避免删除会话同时破坏格式升级前的恢复点。删除确认须说明旧备份可能仍含已删除内容，并提供备份目录入口供用户自行删除；恢复说明须指出恢复会回到旧时点。接受历史备份保留内容的代价，不宣称删除会话已擦除所有副本。未回收 worktree 工作成果继续遵守 ADR-0001 的保留规则，不因删除会话直接销毁。

依据：2026-10-29 M2 grilling Q43 用户确认；实施见 20/32/33 号票，发布回归由 34 号票核对。
