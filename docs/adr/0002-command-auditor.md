# 灰区命令可经模型审计放行，硬规则与明确人工审批保持优先

M2 使用单次无工具的审计模型辅助判断确定性规则无法定性的 command，输出放行、禁止或询问。接受低风险灰区自动放行的误判风险，以减少一律人工确认的打断；已知硬拒、权限档、计划范围、公共操作角色限制及明确人工审批要求仍不可由模型豁免。审计失败转人工，不默认为放行；MCP 暂不纳入。

审计是额外的风险判断，不构成任意程序的系统级隔离。复用现有异步挂起/恢复和单次模型调用，审计结论绑定本次调用且与人工批准分离。决策依据：2026-10-29 M2 grilling Q24–Q26；实施见 36 号票。

用户确认 Q27–Q29：设置专用模型，未配跟随会话；使用独立提示词和授权范围内只读证据，不带全历史、无工具。总等待最多 15 秒，过程与简短结论可见，实际用量计入会话而不增加主任务轮次。
